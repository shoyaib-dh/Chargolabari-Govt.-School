# ৪৪ নং চরগোলাবাড়ী সরকারি প্রাথমিক বিদ্যালয় — অফিসিয়াল ওয়েবসাইট ও অ্যাডমিন পোর্টাল

**ঠিকানা:** চরগোলাবাড়ী, মাদারগঞ্জ, জামালপুর, বাংলাদেশ  
**প্রযুক্তি:** React, TypeScript, Tailwind CSS, Firebase Authentication, Cloud Firestore, Firebase Storage, Vercel SPA

---

## প্রধান বৈশিষ্ট্যসমূহ

### পাবলিক ওয়েবসাইট
- **হোমপেজ (`/`):** ফুল-উইথ ইমেজ স্লাইডার, স্বাগতম সেকশন, অ্যানিমেটেড পরিসংখ্যান, প্রধান শিক্ষকের বাণী ও স্বাক্ষর, বিদ্যালয়ের ৬টি বিশেষত্ব, শিক্ষক প্রিভিউ, নোটিশ বোর্ড (`NEW` ব্যাজসহ), ফটো গ্যালারি প্রিভিউ, সাম্প্রতিক কার্যক্রম এবং গুগল ম্যাপসহ ফুটার।
- **আমাদের বিদ্যালয় (`/about`):** ইতিহাস, পরিচিতি, প্রতিষ্ঠার ইতিহাস ও সাল, লক্ষ্য ও উদ্দেশ্য, মিশন ও ভিশন, অবকাঠামো, সুযোগ-সুবিধা, অর্জন ও জাতীয় দিবস—মোট ৯টি সম্পাদনাযোগ্য বিভাগ।
- **শিক্ষকবৃন্দ (`/teachers`):** শ্রেণিবিভাগ ফিল্টার (প্রধান শিক্ষক, সহকারী শিক্ষক, অন্যান্য শিক্ষক), সার্চ এবং বিস্তারিত প্রোফাইল মডাল।
- **শিক্ষার্থী (`/students`):** প্রথম থেকে পঞ্চম শ্রেণি পর্যন্ত শ্রেণিভিত্তিক পরিসংখ্যান ও অভিভাবকের সম্মতি/অ্যাডমিন অনুমোদন সাপেক্ষে শিক্ষার্থী প্রোফাইল।
- **একাডেমিক কার্যক্রম (`/academics`):** পাঠ্যক্রম, দৈনিক ও সাপ্তাহিক রুটিন, পরীক্ষার সময়সূচি, ছুটির তালিকা ও নথি ডাউনলোড।
- **নোটিশ বোর্ড (`/notices` ও `/notices/:id`):** ক্যাটাগরি ফিল্টার, সার্চ এবং বিস্তারিত নোটিশ পেজ।
- **পরীক্ষার ফলাফল (`/results`):** শ্রেণি, শিক্ষাবর্ষ ও পরীক্ষা অনুযায়ী ফলাফল ও PDF/Excel ডাউনলোড।
- **ফটো ও ভিডিও গ্যালারি (`/gallery`):** ৮টি ক্যাটাগরি ফিল্টার, ম্যাসনারি গ্রিড, ফুল-স্ক্রিন লাইটবক্স ও ভিডিও গ্যালারি।
- **সংবাদ ও কার্যক্রম (`/news` ও `/news/:id`):** পূর্ণাঙ্গ সংবাদ পাতা।
- **যোগাযোগ (`/contact`):** বিদ্যালয়ের ঠিকানা, গুগল ম্যাপ ও Firestore-সংযুক্ত যোগাযোগ ফর্ম।

### কাস্টম অ্যাডমিন প্যানেল
- **লগইন রুট:** `/admin/login`
- **ড্যাশবোর্ড রুট:** `/admin/dashboard`
- **প্রাথমিক অ্যাডমিন ইউজারনেম:** `shoyaib` (সুরক্ষিত Firebase Authentication ও Role-Based Access Control দ্বারা পরিচালিত; সোর্স কোড বা ডাটাবেসে কোনো প্লেইন-টেক্সট পাসওয়ার্ড সংরক্ষণ করা হয় না)।
- **২০টি ব্যবস্থাপনা মডিউল:** ড্যাশবোর্ড, ওয়েবসাইট সেটিংস, বিদ্যালয়ের তথ্য, লোগো ও ফ্যাভিকন, হোমপেজ স্লাইডার, শিক্ষক, শিক্ষার্থী, একাডেমিক, নোটিশ, ফলাফল, ফটো গ্যালারি, ভিডিও গ্যালারি, সংবাদ ও কার্যক্রম, পেজ ব্যবস্থাপনা, যোগাযোগ বার্তা, মেনু ব্যবস্থাপনা, ইউজার ব্যবস্থাপনা, পাসওয়ার্ড পরিবর্তন, ব্যাকআপ ও এক্সপোর্ট (JSON) এবং লগআউট।

## Vercel-এ ডিপ্লয় করার ধাপে ধাপে নির্দেশিকা (বাংলায়)

### ধাপ ১: GitHub-এ কোড আপলোড (Push) করুন
1. আপনার GitHub অ্যাকাউন্টে একটি নতুন Repository তৈরি করুন (যেমন: `chargolabari-govt-primary-school`)।
2. Google AI Studio বা আপনার কম্পিউটার থেকে সম্পূর্ণ সোর্স কোড GitHub Repository-তে Push করুন:
   ```bash
   git init
   git add .
   git commit -m "Initial school website and admin dashboard"
   git branch -M main
   git remote add origin https://github.com/<আপনার-ইউজারনেম>/chargolabari-govt-primary-school.git
   git push -u origin main
   ```

### ধাপ ২: Vercel-এ প্রজেক্ট ইমপোর্ট ও বিল্ড
1. [vercel.com](https://vercel.com)-এ লগইন করুন এবং **Add New → Project** বাটনে ক্লিক করুন।
2. আপনার GitHub Repository-টি নির্বাচন করে **Import** করুন।
3. নিচের Build Settings নিশ্চিত করুন (Vite প্রজেক্টের জন্য সাধারণত স্বয়ংক্রিয়ভাবে সেট থাকে):
   - **Framework Preset:** `Vite`
   - **Build Command:** `npm run build`
   - **Output Directory:** `dist`
4. প্রজেক্টে `vercel.json` ফাইল থাকায় `/admin/login`, `/admin/dashboard`, `/notices/:id` ইত্যাদি SPA রুট সরাসরি কাজ করবে।
5. **Deploy** বাটনে ক্লিক করুন।

### ধাপ ৩: Firebase Console-এ ডোমেইন অনুমোদন (অত্যন্ত গুরুত্বপূর্ণ)
Vercel থেকে আপনার লাইভ ওয়েবসাইটের ডোমেইন পাওয়ার পর (যেমন: `your-school.vercel.app`):
1. [Firebase Console](https://console.firebase.google.com)-এ গিয়ে আপনার প্রজেক্টটি খুলুন।
2. বাম মেনু থেকে **Authentication → Settings → Authorized domains**-এ যান।
3. **Add domain** বাটনে ক্লিক করে আপনার Vercel ডোমেইনটি (যেমন: `your-school.vercel.app`) যুক্ত করুন।
4. (ঐচ্ছিক) ইমেইল ও পাসওয়ার্ড দিয়ে লগইন চালু করতে চাইলে **Authentication → Sign-in method → Email/Password** সক্রিয় করুন এবং **Storage** চালু করলে বড় PDF/Excel সরাসরি Firebase Storage-এ আপলোড হবে।

### ধাপ ৪: প্রথমবার অ্যাডমিন লগইন ও প্রকৃত তথ্য সংরক্ষণ
1. লাইভ সাইটের `/admin/login` পেজে গিয়ে Google Sign-In দিয়ে প্রবেশ করুন।
2. ড্যাশবোর্ডে প্রবেশ করে **"ডাটাবেসে নমুনা তথ্য সংরক্ষণ করুন"** বাটনে ক্লিক করুন অথবা সরাসরি প্রতিটি সেকশনে বিদ্যালয়ের আসল তথ্য, ছবি, শিক্ষক তালিকা, নোটিশ এবং ফলাফল যুক্ত করুন।
